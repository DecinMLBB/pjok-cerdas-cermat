# PJOK ARENA — FINAL MASTER

Build mobile-first untuk Cerdas Cermat PJOK SMP Kelas VII.

## Isi
- Home anime/game UI
- 100 avatar dari satu sprite sheet
- Profile + pilih avatar
- Quiz 10 soal acak dari `questions.js`
- Timer 15 detik, combo, skor, hasil
- Leaderboard Sepuh permanen + ranking peserta
- Leaderboard lokal langsung bekerja
- Supabase online opsional
- Materi, Game Seru, Pengumuman, Tentang Pa Denny
- Backsound YouTube video `BpcdiYYEmvE`

## Supabase online
1. Buka Supabase SQL Editor.
2. Jalankan `supabase-setup.sql` satu kali.
3. Aktifkan Anonymous Sign-Ins.
4. Publish project GitHub Pages.

Kalau Supabase belum disiapkan, website tetap bekerja memakai localStorage.

## Asset
Semua path asset sudah konsisten. Jangan rename folder `assets`.
