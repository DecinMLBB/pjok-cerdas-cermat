# PJOK ARENA — FINAL + ASSET PACK

Website mobile-first Cerdas Cermat PJOK SMP Kelas VII.

## Asset utama
- `assets/home/hero.jpg`
- `assets/profile/avatar-sheet-100.png` — 100 avatar, 10x10 dalam satu gambar
- Background terpisah untuk Home, Profile, Quiz, Leaderboard, Result, Announcement, About
- SVG UI icons

## Avatar
Di Profile, siswa dapat memilih 1 dari 100 avatar. Yang disimpan di localStorage adalah `avatarIndex` 1–100.

## Jalankan
Upload semua isi folder ini ke repository GitHub Pages. Jangan hanya upload folder `assets`; file `index.html`, `app.js`, `style.css`, dan `questions.js` juga harus ikut.
